# onlyPGP

A simple PGP key management and encryption app for iPhone.

(screenshot coming soon)


## Features

- Generate PGP key pairs on device
- Import and export PGP keys (.asc files)
- Encrypt and decrypt text messages
- Sign and verify messages
- Search public keyservers
- QR code key exchange
- iTunes File Sharing support for key transfer
- Secure passphrase handling with automatic memory clearing


## Building

Requires Xcode 5.1 or later.

1. Clone the repository
2. Run `pod install` in the project directory
3. Open `onlyPGP.xcworkspace` (not the .xcodeproj)
4. Build and run


## Requirements

- iOS 7.0 or later
- iPhone
